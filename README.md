# Финальный проект: Android-приложение "Статьи" (Article App)

## Описание
Приложение для чтения статей с поддержкой Offline-first кэширования, добавления в избранное и поиска по локальной базе данных. Приложение работает по паттерну MVVM с использованием Jetpack Compose.

## Технологии
- **Язык:** Kotlin
- **UI:** Jetpack Compose, Material Design 3
- **Архитектура:** MVVM (UiState, UiEvent, StateFlow)
- **DI (Внедрение зависимостей):** Dagger Hilt
- **База данных (Кэш):** Room Database
- **Сеть:** Retrofit + Gson
- **Навигация:** Navigation Compose
- **Загрузка картинок:** Coil

## API Документация
Используется публичный API: [JSONPlaceholder](https://jsonplaceholder.typicode.com/posts)
- **Endpoint:** `GET /posts`
- **Описание:** Возвращает список постов (статей) с полями `id`, `title`, `body`.
- **Ограничения:** API не поддерживает авторизацию или изменение данных (только чтение).

## Функционал
1. **Список статей (LazyColumn)**: Загружает данные с сервера при первом запуске, сохраняет в Room и отображает. Поддерживает скролл.
2. **Избранное (LazyColumn)**: Отдельный экран, отображающий статьи с флагом `isFavorite = true`. Переключение статуса происходит через `UPDATE` запрос в Room.
3. **Поиск**: Мгновенная фильтрация статей по заголовку и тексту через SQL-запрос `WHERE title LIKE ...` в Room.
4. **Детали**: Отображение полной информации о статье (картинка, заголовок, текст) по её ID.
5. **Offline-first**: При наличии интернета данные скачиваются и кэшируются. При отсутствии сети приложение отображает последний закэшированный список из базы данных.

## Архитектура (Offline-first)
`UI (Compose) -> ViewModel (StateFlow) -> Repository -> (Room DB / Retrofit API)`
Приложение подписано на `Flow` из Room. При старте выполняется запрос к API, данные сохраняются в БД (с сохранением статуса избранного), а UI автоматически обновляется благодаря реактивности Room.

## Как запустить
1. Откройте проект в Android Studio.
2. Дождитесь синхронизации Gradle.
3. Запустите на эмуляторе или физическом устройстве (Min SDK 24).
4. При первом запуске требуется интернет для синхронизации данных с сервером.
